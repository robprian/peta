Peta Indonesia — GIS & Geocoding

Pemilih lokasi Leaflet dengan reverse geocoding, autocomplete, hierarki wilayah, dan postMessage.

Demo statis. Halaman ini berjalan tanpa backend: data contoh area Cibaduyut/Bandung tertanam di peramban. Aplikasi produksi memakai FastAPI + PostgreSQL/PostGIS, yang tidak dapat dijalankan di GitHub Pages. Untuk data Indonesia penuh, jalankan backend dari repositori lalu arahkan widget ke apiBase Anda.
